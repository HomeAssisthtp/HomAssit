# 🏠 HomAssit - Monitoreo del Hogar con Detección Inteligente
Es un sistema de asistencia, monitoreo y seguridad para el hogar que integra una plataforma web con dispositivos IoT, permitiendo supervisar de forma accesible y funcional las condiciones ambientales y de seguridad de una vivienda.

[![Estado del Proyecto](https://img.shields.io/badge/Sprint%201-Completado-success)](https://github.com/)
[![Sprint 2](https://img.shields.io/badge/Sprint%202-En%20Proceso-blue)](https://github.com/)
[![Scrum](https://img.shields.io/badge/Metodología-Scrum-orange)](https://github.com/)

HomeAssist es una solución integral orientada a hogares unipersonales y personas en situación de vulnerabilidad. Combina hardware libre basado en el microcontrolador **ESP32**, una plataforma web responsiva y un módulo analítico de **Inteligencia Artificial** para validar eventos, diagnosticar la salud de la red y suprimir falsas alarmas provocadas por fluctuaciones o desconexiones de sensores.
